Event Management System
Version 1 Scope
1. System Overview
The proposed solution is a web-based Event Management System designed to manage medical
conferences and events from event creation through participant registration, payment
verification, ticket generation, certificate issuance, and reporting.
The solution includes three portals:
* Public Website
* Administration / Back Office Portal
* Self-Service Event Kiosk (On-site)
The system language will be:
* English
Supported currencies:
* Egyptian Pound (EGP)
* US Dollar (USD)

Module 2
Online Registration
Doctors can register through the website.
Registration Form includes:
* Full Name
* Mobile Number
* Email Address
* Address
* Country
* City
* Specialty
* Nationality
Once submitted:
* Doctor Profile is created.
* Registration Request is created.
* Payment Status = Pending.
* Ticket is NOT generated until payment approval.
